This chapter is for developers changing AGW or integrating with its APIs. For installation and everyday use, start with [Getting started]({{< relref "/docs/start" >}}).

Complete [Development setup]({{< relref "/docs/development/setup" >}}), then use [Architecture]({{< relref "/docs/development/architecture" >}}) to locate the right module. Read [APIs and execution protocols]({{< relref "/docs/development/api" >}}) for client integrations, [Extend tools and integrations]({{< relref "/docs/development/extensions" >}}) for built-in capabilities, and [Build Server and Desktop extensions]({{< relref "/docs/development/extension-sdk" >}}) for loadable extension packages. Before submitting changes, follow the relevant [testing and contribution checks]({{< relref "/docs/development/testing" >}}).
