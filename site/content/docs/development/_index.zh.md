本章面向准备修改 AGW 源码或接入 API 的开发者。只想安装和使用 AGW，可以先阅读[快速开始]({{< relref "/docs/start" >}})。

建议先完成[开发环境]({{< relref "/docs/development/setup" >}})，再用[架构与模块边界]({{< relref "/docs/development/architecture" >}})判断代码应放在哪里。接入客户端时阅读[API 与执行协议]({{< relref "/docs/development/api" >}})，新增内置能力时阅读[扩展 Tools 与 Integrations]({{< relref "/docs/development/extensions" >}})，编写可加载扩展时阅读[开发 Server 与 Desktop 扩展]({{< relref "/docs/development/extension-sdk" >}})。提交改动前，按[测试与贡献约定]({{< relref "/docs/development/testing" >}})完成相关验证。
