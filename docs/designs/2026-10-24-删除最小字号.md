# 删除最小字号

## 名词解释

- **按比例缩小的文字**：字号写为容器字号或根字号的倍数且倍数小于 1 的文字，例如行内代码（`0.875em`）、表格（`0.9375em`）、脚注（`0.875em`）、脚注引用（`0.75em`），以及 Tailwind 的 `text-xs`（`0.75rem`）、`text-sm`（`0.875rem`）等主题字号。
- 其余名词（基础字号、聊天字号、文档字号、代码字号、排版规范、主题变量等）沿用 `2026-10-21-Markdown排版规范与Desktop字号设置.md` 与 `2026-10-22-Text-Editor设置.md`。

## 背景

- `2026-10-21` 方案给所有按比例缩小的文字设置了下限 `--agw-font-size-min`：排版规范与 Text Editor 的样式写为 `max(var(--agw-font-size-min), …)`，Desktop 把 7 个小于 1rem 的 Tailwind 主题字号改写为 `max(var(--agw-font-size-min), 原值)`，各字号设置的可选范围也受它限制。当前代码中这个下限固定为 14px。
- 用户不需要最小字号：按比例缩小的文字应当始终按比例缩放，各字号设置的可选范围从 12 开始。

## 设计目标

### 功能目标

1. 删除最小字号：没有 `--agw-font-size-min`，按比例缩小的文字只按比例计算，Desktop 与 Web 相同。
2. 各字号设置的可选范围：基础字号 12–20，聊天字号 12–24，Text Editor 的文档字号与代码字号 12–28。
3. 聊天字号跟随基础字号时为基础字号 × 0.875；Text Editor 的文档字号跟随时为基础字号，代码字号跟随时为文档字号 × 0.875 并取整到 0.5px。

### 技术目标

- 主题变量删除 `--agw-font-size-min`，推送给 extension 的字号变量只有 `--agw-font-size-base`。`manifestVersion` 仍为 1；`--agw-font-size-min` 只在未发布的 `2026-10-21` 方案中出现过，使用它的只有 Text Editor。
- 不做 `settings.json` 迁移：Desktop `appearance` 与 Text Editor 设置文件的已有值（14 及以上）都在新范围内，读取结果不变。

## 详细设计

### 1. 排版规范与宿主样式

- `packages/components/src/ui-tokens/typography.css`：
  - `:root` 删除 `--agw-font-size-min`。
  - `--agw-prose-size` 在 `compact` 密度为 `var(--agw-prose-font-size, var(--agw-font-size-chat))`，在 `document` 密度为 `var(--agw-prose-font-size, var(--agw-font-size-document))`。
  - 行内代码、代码块、脚注区为 `0.875em`，表格为 `0.9375em`，脚注引用为 `0.75em`。
- `packages/components/src/ui-tokens/tokens.css`：
  - 删除只在 Desktop 生效的 `.prose-sm` 与 `.prose :where(code, pre, table)` 下限规则，Desktop 与 Web 使用相同的 `.prose` 样式。
  - 聊天代码块标题栏（`.msg-content-md-code-header`）与其他局部样式的字号为 `0.875em`。

### 2. Desktop

- `shared/appearance.ts` 删除 `MIN_FONT_SIZE`；`BASE_FONT_SIZES` 为 12–20，`CHAT_FONT_SIZES` 为 12–24；`resolveFontSizes` 的聊天字号为 `chatFontSize ?? baseFontSize × 0.875`。
- `settings-store.ts` 的 zod 严格对象：`baseFontSize` 为整数 12–20，`chatFontSize` 为 `null` 或整数 12–24。
- `resolveAppearance` 只输出 `--agw-font-size-base` 与 `--agw-font-size-chat`，不改写 Tailwind 主题字号：`text-xs` 等按 `tokens.css` 中的 `rem` 值随基础字号缩放（基础字号 16 时 `text-xs` 为 12px）。
- `THEME_TOKEN_NAMES` 删除 `--agw-font-size-min`。
- Appearance 页面的下拉框按新范围列出选项。

### 3. Text Editor

- `TEXT_EDITOR_FONT_SIZES` 与设置文件的校验范围为 12–28。
- `resolveTextEditorFontSizes(settings, tokens)` 只读取 `--agw-font-size-base`，返回 `{ document, code }`：`document = documentFontSize ?? base`；`code = codeFontSize ?? round(document × 0.875 × 2) / 2`。主题变量缺少 `--agw-font-size-base` 或不是 px 值时抛出。
- `code.css`、`edit.css`、`markdown.css`、`settings.css`、`document-error.css` 中按比例缩小的字号只写倍数，例如 `0.875em`、`0.85em`。
- 测试宿主（`src/test-host.ts` 等）的主题变量删除 `--agw-font-size-min`。

### 4. Extension SDK

- `ThemeInfo.tokens` 的说明中字号变量只列出 `--agw-font-size-base`，重新生成 `sdk.d.ts`。

### 5. 对旧方案的取代

本方案取代 `2026-10-21` 方案中与最小字号有关的全部内容（名词解释中的 "最小字号"、技术选型 "最小字号使用 CSS `max()` 与 Tailwind 的主题变量"、第 1.2 节 `--agw-font-size-min`、第 1.3 节与第 4.3 节的 `max()` 写法、第 2.1 节 `minFontSize` 与跨字段规则、第 2.2 节 "Minimum font size" 与不可选的选项、第 2.3 节 `--agw-font-size-min` 与 Tailwind 字号下限、第 4.1 节主题变量中的 `--agw-font-size-min`、第 6 节与第 7 节中 14px 的说明、测试计划中与最小字号有关的项），以及 `2026-10-22` 方案中的 `--agw-font-size-min`、第 2 节字号计算中的 `max()`、第 4 节小于最小字号的选项处理。

## 接口文档

- `AppearanceSettings` 的字号字段：`baseFontSize`（整数 12–20）、`chatFontSize`（`null` 或整数 12–24）。
- 主题变量：字号变量只有 `--agw-font-size-base`。
- Text Editor `settings.json`：`documentFontSize`、`codeFontSize` 为 `null` 或整数 12–28。
- `resolveTextEditorFontSizes(settings, tokens): { document: number; code: number }`。

## 测试计划

### 单元测试

- `settings-store.test.ts`：12、20、24 可读；11、21、25 加载失败；保存 11 被拒绝。
- `resolve-appearance.test.ts`：默认 16、14 px；基础字号 12 时聊天字号 10.5 px；只输出 `--agw-font-size-base` 与 `--agw-font-size-chat`。
- `appearance-provider.test.ts`：根元素的 inline style 只有 `font-size`、`--agw-font-size-base`、`--agw-font-size-chat`。
- `appearance-settings-form.test.ts`：基础字号选项 12–20，聊天字号选项 12–24；基础字号 12 时 "Follow base size (10.5 px)"。
- `extension-host-provider.test.ts`：`THEME_TOKEN_NAMES` 包含 `--agw-font-size-base`。
- Text Editor：`resolveTextEditorFontSizes`（主题变量只有 `--agw-font-size-base`；默认 16、14；文档字号 12 时代码 10.5）；设置文件 12、28 可读，11、29 读取抛出；设置页选项为 "follow" 与 12–28。
